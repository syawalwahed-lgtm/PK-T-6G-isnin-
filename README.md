# Misi Sihat! — Pendidikan Kesihatan Tahun 6

Laman pembelajaran interaktif berbahasa Melayu dengan video pengenalan, nota infografik, latihan pantas dan kuiz arcade 20 soalan.

## Kandungan
- `index.html` — halaman utama
- `style.css` — gaya visual responsif, animasi dan paparan mudah alih
- `script.js` — interaksi, soalan kuiz, markah, bintang, bunyi dan suara
- `assets/video-pengenalan.mp4` — video pengenalan yang dibekalkan

## Cara guna
1. Ekstrak fail ZIP.
2. Buka `index.html` menggunakan pelayar moden (Chrome, Edge, Firefox atau Safari).
3. Tekan butang Bunyi untuk mengaktifkan/menyahaktifkan bunyi. Suara Bahasa Melayu bergantung pada suara yang tersedia pada peranti/pelayar.
4. Untuk hos web, muat naik semua fail dan folder dengan struktur yang sama.

## Terbitkan ke GitHub Pages
1. Log masuk ke GitHub dan cipta repository baharu, contohnya `pk-tahun6-misi-sihat`.
2. Muat naik `index.html`, `style.css`, `script.js`, dan folder `assets/`.
3. Buka **Settings → Pages**.
4. Di bahagian **Build and deployment**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, kemudian **Save**.
5. Selepas GitHub Pages menerbitkan laman, GitHub akan memaparkan URL laman dalam bahagian Pages.

Saya tidak menerbitkan terus ke akaun GitHub kerana akses akaun/pengesahan tidak diberikan dalam sesi ini. ZIP ini sedia dimuat naik ke repository GitHub anda.

## Penjajaran DSKP
Kandungan ini dirangka sebagai ulang kaji pelbagai topik Pendidikan Kesihatan Tahun 6: pemakanan, penyalahgunaan bahan, pengurusan emosi/asertif, penyakit bawaan makanan dan air, keselamatan diri serta bantu mula. Semak DSKP terkini yang digunakan oleh sekolah sebelum pelaksanaan rasmi kerana susunan atau versi dokumen boleh berbeza.

## Nota teknikal
- Tiada pustaka JavaScript luaran diperlukan. Google Fonts digunakan jika sambungan internet tersedia; fon sistem menjadi pilihan sandaran.
- Audio maklum balas dijana oleh Web Audio API; suara menggunakan Speech Synthesis dan bergantung pada sokongan peranti.
- Kuiz disusun semula secara rawak setiap kali permainan bermula.
